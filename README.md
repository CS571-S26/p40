# ShopWise 🛒

ShopWise is a grocery comparison web application designed to help users, especially students, save money by comparing prices across different stores and optimizing their grocery list.

## 🚀 Features

- Compare prices of grocery items across Walmart, Target, and Costco  
- Optimize a grocery list to find the cheapest combination of stores  
- View the best single-store option for bulk shopping  
- Filter items by category for easier browsing  
- Clean and responsive UI built with React Bootstrap  

## 🛠️ Tech Stack

- React  
- React Router  
- Vite  
- React Bootstrap
